# 51ape（at38.cn）渠道说明

网页与客户端均新增两个独立渠道：网易云音乐下的 `at38-netease`、QQ 音乐下的 `at38-qq`，对用户统一显示为“51ape”。当前公开页面没有发现酷狗、酷我或咪咕搜索结果，未注册这些平台的 51ape 渠道。

## 已确认的公开接口

- 搜索：`GET https://www.at38.cn/?keyword=关键词`，HTML 的 `.music-card` 提供 `data-id`、`data-type`、歌曲名、歌手、专辑。
- 平台标识：`wy` 为网易云，`qq` 为 QQ 音乐。搜索请求返回混合结果，各 provider 只保留自己的平台结果，原始歌曲 ID 不做跨平台转换。
- 播放：`GET /?action=play&id=歌曲ID&type=wy或qq`，返回音频跳转。
- 下载链接：`GET /?action=geturl&id=歌曲ID&type=wy或qq&filename=文件名`，返回包含 `code=1`、`url`、`filename` 的 JSON。项目使用该接口解析地址，随后沿用已有音频链接校验。
- 首次访问：可能先返回设置 `mk_visit` 的加载页。实现仅提取字面 Cookie 并重试请求，不执行站点 JavaScript。
- 列表分页：只对网站实际返回的完整结果做按平台过滤及本地切片，不假定存在未公开的远程分页接口。

## 调研记录

2026-10-22，对用户提供的“周杰伦”搜索页取得网易云、QQ 音乐各 10 条结果。两边分别抽查两首歌曲，下载链接均返回 HTTP 206 和 MP3 文件头，音频分别来自网易云和 QQ 音乐 CDN，响应包含 `Access-Control-Allow-Origin: *`。两个平台各抽查一首 `action=play`，同样返回有效 MP3 响应。

样本使用现有网页下载方式，支持网页直接下载与批量下载；不额外标为浏览器逐首交接渠道。后续网页交互、部署环境及完整客户端行为由用户自行验证，本次未操作项目浏览器或运行项目测试。

歌曲列表与脱敏接口结果保存在 `docs/diagnostics/at38-discovery-2026-10-22.json`。播放入口可以长期按 ID 构造，解析后的 CDN 链接可能过期，不应长期缓存。
